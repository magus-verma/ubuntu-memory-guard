# Support

Read the [compatibility guide](docs/compatibility.md) and
[troubleshooting guide](docs/troubleshooting.md) first. Search existing issues
before opening a bug report or feature request.

For a bug, provide the guard version, distribution, kernel, Python, systemd,
architecture, sanitized `--status` output, relevant service journal messages,
and reproduction steps. The issue form lists these fields.

For security problems, follow [SECURITY.md](SECURITY.md). Community support is
best-effort; this project does not provide a support or crash-prevention SLA.
